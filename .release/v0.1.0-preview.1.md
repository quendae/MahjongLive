# Mahjong Live v0.1.0-preview.1

Pierwszy publiczny build podglądowy obecnego stanu projektu z gałęzi `feature/visual-table-replay`.

## Co warto sprawdzić

- szybki stół 2D i pełny stół 3D;
- deterministyczną rozgrywkę Riichi Mahjong;
- CHI / PON / KAN / RON oraz prezentację meldów;
- Dora, Riichi stick, Tenpai/Furiten i objaśnienia punktacji;
- boty Casual / Standard / Expert;
- historię meczu oraz wizualny replay 2D/3D z prędkościami 0.5x / 1x / 2x / 4x;
- opcje wyglądu, jakości 3D i skalowania interfejsu;
- telemetrykę wydajności / FPS w narzędziach deweloperskich.

## Stan jakości

Przed przygotowaniem release'u HEAD przeszedł pełny Shared Engine CI oraz Responsive Table QA. Deterministyczny rules audit przechodzi sześć pełnych Hanchan bez zmiany wyników po dodaniu rule-profile plumbing.

## Uruchomienie ZIP-a

Archiwum zawiera gotowy statyczny build. Po rozpakowaniu uruchom w jego katalogu prosty serwer HTTP, np.:

```text
python -m http.server 8080
```

Następnie otwórz `http://localhost:8080`.

To jest **pre-release testowy**, nie finalna wersja. PR #33 pozostaje niezmergowany.
