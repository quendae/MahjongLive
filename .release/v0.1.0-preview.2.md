# Mahjong Live v0.1.0-preview.2

Drugi build podglądowy przeznaczony do normalnego ogrywania i zgłaszania problemów z UX/presentation.

## Najważniejsze zmiany względem preview.1

- poprawiony tryb 2D: klocek deklaracji Riichi nie obraca się ponownie po kolejnych discardach;
- poprawiona animacja discardu 2D: usunięty sztuczny podskok/łuk przed lądowaniem;
- ostatni discard pozostaje dokładnie w swoim rzędzie zamiast być podnoszony o kilka pikseli;
- zachowany source-aware ruch tsumogiri/tedashi bez drugiej animacji lądowania;
- dodane testy regresyjne dla obu powyższych problemów;
- rule-profile plumbing i kompatybilność starszych save-state'ów pozostają aktywne;
- deterministyczny rules audit, bot benchmark, client typecheck/build oraz pełny responsive browser QA pozostają zielone.

## Co testujemy w tym buildzie

Najważniejszy jest teraz zwykły pełny mecz w 2D. Zwróć uwagę szczególnie na:

- Riichi — sideways tile powinien obrócić się raz i już pozostać nieruchomy;
- każdy discard — płynny lot do rivera bez podskoku przy lądowaniu;
- CHI / PON / KAN i ustawienie wywołanego klocka;
- Dora i kolejne Kan-Dora;
- reakcje RON / PON / CHI / PASS;
- przejście pomiędzy rundami i końcowy wynik;
- save/resume po odświeżeniu strony;
- historię i visual replay po zakończeniu kilku rund.

## Uruchomienie

Archiwum zawiera gotowy statyczny build. Po rozpakowaniu uruchom w jego katalogu prosty serwer HTTP, np.:

```text
python -m http.server 8080
```

Następnie otwórz `http://localhost:8080`.
