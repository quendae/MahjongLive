# Mahjong Live v0.1.0-preview.3

Aktualny build testowy z najnowszego stanu gałęzi `feature/visual-table-replay`.

## Najważniejsze zmiany względem preview.2

- domknięty cross-browser QA dla Chromium, Firefox i WebKit;
- dodany prawdziwy test mobilnego `tap()` w Chromium (setup, Options, UI scale i discard);
- poprawiony fallback 3D: jeśli WebGL nie jest dostępny, gra wraca do grywalnego 2D i pokazuje `2D · 3D unavailable` zamiast wisieć w stanie loading;
- poprawiona synchronizacja testu zintegrowanej Dory w WebKit przy 844×390 bez zmiany wyglądu/CSS gry;
- nadal zawiera poprawki 2D z preview.2: stabilny sideways Riichi discard i brak sztucznego podskoku przy lądowaniu discardu;
- zachowane visual replay/history, UI scale/accessibility, rule-profile/save compatibility, deterministic rules audit i bot benchmark.

```text

```
